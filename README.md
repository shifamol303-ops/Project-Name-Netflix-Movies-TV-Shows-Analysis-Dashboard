# Netflix Movies & TV Shows Analysis Dashboard

## Project Overview
This project analyzes Netflix movies and TV shows using Tableau Public. The dashboard provides visual insights into Netflix content by country, genre, rating, release year, and content type.

## Objectives
- Analyze the distribution of movies and TV shows.
- Explore Netflix content across countries.
- Identify the top 10 genres.
- Understand rating distribution.
- Analyze content trends by year.

## Tools Used
- Tableau Public
- Microsoft Excel / CSV
- Data Visualization

## Dashboard Features
- Country-wise content distribution map
- Ratings analysis
- Top 10 genres
- Movies vs. TV Shows comparison
- Year-wise content trends
- Interactive filters for Type and Title
- Detailed information about selected titles

## Key Insights
- Movies account for a larger share of titles than TV shows in this dataset.
- Documentaries and stand-up comedy are among the leading genres shown in the dashboard.
- The dashboard shows a rise in content additions during 2017–2019.

## Dataset
Netflix Movies and TV Shows dataset (`netflix_titles.csv`).

## How to Use
1. Download or clone this repository.
2. Open Tableau Public or Tableau Desktop.
3. Connect to the `netflix_titles.csv` dataset.
4. Open the Tableau workbook (`.twbx`) if included.
5. Explore the dashboard using the available filters.

## Conclusion
This project demonstrates how Tableau can transform raw data into interactive visualizations and meaningful insights. It helped develop practical skills in data analysis, visualization, and dashboard design.
